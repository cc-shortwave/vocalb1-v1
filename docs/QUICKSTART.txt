VocalB1 QUICKSTART
=================

EN
--
1. Unzip this folder anywhere (keep the whole folder together).
2. Put a UTAU 単独音 voicebank into the "voicebank" subfolder, for example
       voicebank\<your-voicebank>\oto.ini
       voicebank\<your-voicebank>\_a.wav ... (142 basic kana)
   No voicebank is bundled, for licensing reasons.
3. Double-click VocalB1.exe.
   - full build : a bundled Python is included, nothing to install.
   - lite build : needs Python 3.10+ on PATH, then
                      pip install -r requirements.txt
4. Pick a sample melody, drag on the canvas to place notes, press "Re-render".

中文
----
1. 把整个文件夹解压到任意位置（别把里面的文件拆散）。
2. 把 UTAU「単独音」声库放进 voicebank 子目录，例如
       voicebank\<你的声库>\oto.ini
       voicebank\<你的声库>\_あ.wav …（需要 142 个基本假名）
   出于版权原因，不附带任何声库。
3. 双击 VocalB1.exe 启动。
   - full 版：已内置 Python，不需要额外安装。
   - lite 版：需要系统里装了 Python 3.10+ 并在 PATH 中，然后执行
                  pip install -r requirements.txt
4. 选一首参考曲，在画布上拖动建音，按「重新合成」即可试听。

日本語
------
1. フォルダごと任意の場所に解凍してください（中のファイルを分けないでください）。
2. UTAU の「単独音」音源を voicebank サブフォルダに置きます。
   例: voicebank\<お使いの音源>\oto.ini
   ライセンスの都合で、音源は同梱していません。
3. VocalB1.exe をダブルクリックして起動します。
   - full 版 : Python を内蔵しているので追加インストールは不要です。
   - lite 版 : Python 3.10 以上が PATH に必要です。その後
                   pip install -r requirements.txt
4. 参考曲を選び、キャンバスをドラッグして音を置き、「再合成」で試聴できます。
