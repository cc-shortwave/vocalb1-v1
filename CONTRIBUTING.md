# Contributing

Thanks for your interest in VocalB1.

## Scope

Welcome: UI layout, styles, icons, motion, copy, translations,
accessibility fixes, and bug reports.

Maintained solely by the maintainer: the synthesis engine
(`VocalB1Synthesizer.py`, `engine/`, `vocal_lib/`), the analysis and
helper scripts (`tools/`), the project format (`.vbp`), the installer
and the release process.

## Pull requests

- One focused change per pull request.
- State what changed, why, and how you verified it.
- Match the existing code style. Ask before adding a dependency.
- Sign off your commits (`git commit -s`).

## Decisions

The maintainer decides what gets merged, and how the UI and the
engine are designed. Disagreement is settled by that decision.
